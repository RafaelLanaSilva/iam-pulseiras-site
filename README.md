# I’am Pulseiras

Site institucional em React + Vite. A página inicial apresenta os seis modelos, possibilidades de personalização, aplicações, processo, galeria e dúvidas. Cada modelo também tem uma página própria. As páginas de catálogo, sobre, contato e informações permanecem disponíveis.

## Desenvolvimento

- `npm run dev` inicia a prévia local.
- `npm run lint` verifica o código.
- `npm run build` gera a versão estática em `dist`, com 13 páginas pré-renderizadas e página 404.
- `npm run preview` abre a versão gerada.

## Imagens

As imagens estão em `public/images/lovable-reference/`. Elas foram extraídas da versão pública do site de referência feito no Lovable. São os arquivos publicados para a web; os originais de geração podem ter resolução maior. A galeria é apresentada como inspiração de uso, sem afirmar que as cenas retratam clientes reais.

## Antes da publicação

Confirmar o pedido mínimo, as descrições e acabamentos dos modelos, o número de WhatsApp, o e-mail e o perfil do Instagram. Preencher as páginas de privacidade, termos e envio antes de torná-las definitivas. O formulário de contato prepara uma mensagem `mailto:`; o envio depende do aplicativo de e-mail do visitante.

Esta versão mantém `noindex, nofollow` para revisão. Remover essa diretiva somente após conferir conteúdo e contatos, definir o domínio final e configurar metadados de compartilhamento, sitemap e robots. Hospedar `dist` com suporte a diretórios com `index.html` e página 404.
